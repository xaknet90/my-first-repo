# my-first-repo

Учебный репозиторий для знакомства с Git и GitHub.

## Что здесь происходит

Этот репозиторий создан, чтобы отработать базовый процесс работы с кодом:

1. Создать ветку для изменений.
2. Сделать коммит.
3. Отправить ветку на GitHub.
4. Открыть pull request (PR) и влить его в `main`.

## Как склонировать

```bash
gh repo clone xaknet90/my-first-repo
```
